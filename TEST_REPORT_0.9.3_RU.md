## Что покрыто тестами (по требованиям ТЗ §10)

**С имитацией сервисов (mock):**
- Русские и английские ответы: промпт на нужном языке, наследование языка в коротких уточнениях, перегенерация при ответе не на том языке (`test_engine093`).
- Обычный разговор без шаблонов: приветствие идёт через модель с персоной и короткой длиной ответа.
- Качество структурированных ответов: детектор повторов, иероглифов, бессвязности, ложного «я поискала в интернете»; одна контролируемая перегенерация; `model_eval` ранжирует модели.
- Интернет-поиск: новости с датами и ссылками, сравнение независимых источников, выключенный переключатель, нет интернета, **нет API-ключа** — честные предупреждения, флаг `search_performed=false`.
- Сохранение и извлечение знаний: дедупликация, версии, архивирование, FTS + эмбеддинги, изоляция личной базы, противоречия, обзор и принятие результатов исследования (`test_knowledge093`).
- Опасные URL: 16 видов (localhost, частные сети, metadata, IPv6 loopback, IPv4-mapped, `.ts.net`, нестандартные порты, логины в URL…), DNS на частный IP, редирект на `127.0.0.1`, привязка соединения к проверенному IP, robots.txt (запрет, 404, 5xx, crawl-delay).
- Prompt injection: вырезается при извлечении и повторно перед промптом, снижает доверие к источнику.
- Вход через Supabase (поддельная проверка токена), изоляция пользователей в Host (чужие диалоги → 404, запись в чужой чат запрещена, остановка чужой генерации запрещена).
- Синхронизация: два хоста одного пользователя без дубликатов, офлайн-изменения выгружаются позже, мягкое удаление и избранное, память (последняя запись побеждает, локальная правка в приоритете), совместимость со схемой 0.9.2.
- Сохранность данных: обновление **реальной схемы 0.9.2** с данными → v3, 3 резервные копии, история/память/страницы сохранены, повторный запуск ничего не меняет, откат из бэкапа и down-миграциями, неудачная миграция откатывается целиком.
- Запуск Gradio при занятом порте: выбирается следующий свободный, явный занятый порт — понятная ошибка.
- Конвейер дообучения: только согласие + 👍, маскировка e-mail, порог качества, откат, без shell-инъекций.

**Интеграционные (настоящие компоненты):**
- Host API v2 по HTTP + клиент `client_api` (`test_host093`): NDJSON-стриминг, остановка, повтор, редактирование, оценки, диалоги, валидация (413/400), права на исследования и общую базу, настройки, старый эндпоинт `/api/chat` 0.9.2.
- PostgreSQL 16: RLS всех таблиц, anon без доступа, нельзя писать от чужого имени, нельзя привязать сообщение к чужому диалогу, upsert без дублей, откат 003 сохраняет сообщения.
- Desktop UI в браузере (с имитацией Ollama по HTTP).

## Ручной сценарий приёмки на устройствах
1. Установить Host, войти, задать «Как дела, Челси?» и «Почему небо голубое?» (рус/англ).
2. «Какая погода в Москве?», «Что произошло сегодня?» (с ключом и без), выключить переключатель интернета.
3. «Изучи документацию FastAPI» → Исследования → принять 2 материала → вопрос по FastAPI показывает «Из базы знаний».
4. Остановить длинный ответ, повторить, отредактировать сообщение, 👍.
5. `tailscale serve --bg 8787`; Windows Client и Android: вход, история, новый чат; выключить Host → клиенты показывают «Хост недоступен», Android — облачную историю.
6. Второй аккаунт не видит диалогов первого (Desktop, клиенты, сайт).
7. Обновление поверх 0.9.2: история и память на месте, в `data\backups` — копии.
