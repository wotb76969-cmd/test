# Chelsy AI 0.8 — Auth Integration Candidate

Новая версия 0.8 на базе рабочей 0.7. Приложение остаётся локальным, но может использовать существующую авторизацию сайта Chelsy Group через Supabase.

## Сборка Windows

1. Установить Python 3.11 и Inno Setup 6/7.
2. Распаковать в папку без русских символов, например `E:\ChelsyBuild08`.
3. Запустить `BUILD_INSTALLER.bat`.
4. После завершения получить `installer\ChelsyAI_Setup_0.8.exe`.
5. Следовать `INTEGRATION_SUPABASE_RU.md`.

В этом архиве **исходники и сборщик**, не готовый EXE. Сборку Windows необходимо проверить на Windows; здесь проверен Python-код и 30 локальных тестов.

## Совместимость

Существующие SQLite и локальные аккаунты не удаляются. При включении Supabase новые чаты привязываются к `auth.users.id`. Объединение старой памяти с новым аккаунтом доступно через `ChelsyMigrate.exe`, с резервной копией. Работа с реальными Supabase-аккаунтами требует указания своего URL и publishable key.
