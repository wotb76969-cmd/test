# Патч ошибки порта 7860

Gradio теперь выбирает первый свободный порт 7860–7890 и не падает, если 7860 занят. Приложение по-прежнему доступно только локально (127.0.0.1). Можно задать собственный порт через GRADIO_SERVER_PORT.

Это исходный код, а не готовый EXE. Чтобы заменить установленную версию, соберите Windows-установщик через BUILD_INSTALLER.bat и установите его. Личные данные в %LOCALAPPDATA%\ChelsyAI не затрагиваются.
