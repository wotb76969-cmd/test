# Chelsy AI Desktop 0.6 — новый интерфейс

Это **полный проект обновления**, созданный на основе Chelsy AI Desktop 0.4, а не отдельный патч.

## Новое в 0.5

- Фирменная тёмная тема в сиренево-графитовом стиле.
- Левое меню: Чат, Исследования, Память, Подключения, Настройки.
- Chelsy Pulse — статус связи с локальной Ollama и количество страниц в памяти.
- Чат с выбором между `llama3.2:1b` и `qwen3:4b` (модель нужно скачать в Ollama).
- Сохранены история, SQLite-память, авторизация `owner`/`tester`, обход разрешённых страниц.
- Обновлена языковая инструкция: отвечать на языке последнего сообщения пользователя (качество зависит от модели).

**Важно:** экран «Подключения» пока информационный. Режим Host/Client и приложение Android **ещё не реализованы**. Сервер всё ещё привязан только к `127.0.0.1`; это безопаснее для локальных тестов. Не открывайте порт 7860 в публичный интернет.

## Обновление без потери памяти

Данные прежней установки находятся в `%LOCALAPPDATA%\ChelsyAI\data`. **Не удаляйте эту папку.**

1. Остановите Chelsy AI (в том числе фоновые процессы).
2. Распакуйте архив исходников в **новую папку**, например `E:\ChelsyBuild05`.
3. Убедитесь, что установлены Python 3.11, Inno Setup 6/7 и Ollama.
4. Запустите `BUILD_INSTALLER.bat` в папке проекта.
5. После успешного сообщения `SUCCESS` найдите `installer\ChelsyAI_Setup_0.6.exe`.
6. Если Inno Setup не обнаружен скриптом: вручную откройте `ChelsyAI.iss` в Inno Setup Compiler и нажмите F9 (это не требует повторной сборки Python).
7. Закройте старую версию и установите новую поверх неё.
8. Запустите Chelsy AI и проверьте Чат → Память → Исследования.

При первом запуске после обновления **старые учётные записи остаются прежними**. Установщик не включает сам Ollama или файлы модели — она должна быть установлена отдельно.

### Если хотите Qwen

```powershell
ollama pull qwen3:4b
```

Переключить модель можно в нижней части чата. На слабом GPU она может отвечать медленнее. Для проверки наличия модели: `ollama list`.

### Диагностика

Журналы ошибок: `%LOCALAPPDATA%\ChelsyAI\error.log` и `runtime.log`.

Прокси иногда ломает локальные вызовы Gradio или Ollama — проверьте, что `localhost` и `127.0.0.1` исключены из проксирования.

### Проверки

В сборщике сначала выполняются `python -m unittest discover -v` и `python preflight.py`, затем PyInstaller и Inno Setup. Если тесты упали, установщик не формируется. Проверить реальную Windows-сборку можно только на Windows.
