# Chelsy AI Desktop 0.6

Это единый проект следующей версии Windows-приложения. Начни с файла **README_0.5_RU.md** — там инструкция по сборке и список изменений.

**Главное:** установщик `.exe` создаётся на Windows запуском `BUILD_INSTALLER.bat`. Этот ZIP содержит исходники и инструменты сборки, а не готовый Windows EXE.

Новая версия сохраняет локальный запуск Ollama, SQLite-память и существующие аккаунты из `%LOCALAPPDATA%\ChelsyAI`.

На текущем этапе экран «Подключения» информационный, удалённый Host/Client и Android приложение ещё не реализованы.
