# Обновления Chelsy AI Desktop

- Установщик с тем же `AppId` устанавливается поверх прежней версии в тот же каталог приложения.
- **Данные пользователя** находятся в `%LOCALAPPDATA%\ChelsyAI\data`, а не в папке программы. Их установщик не стирает.
- Перед обновлением закрывайте программу и проверяйте, что процесс `ChelsyAI.exe` завершён.
- Для последующих выпусков меняйте `MyAppVersion` и `OutputBaseFilename` в `ChelsyAI.iss`, затем собирайте проект на Windows.
- Автоматическое обновление через интернет **пока не реализовано**. Его следует внедрять только с проверкой подписи релиза, HTTPS, откатом и резервным копированием.
- Для массового распространения рекомендуется цифровая подпись установщика и проверка файла антивирусом.
