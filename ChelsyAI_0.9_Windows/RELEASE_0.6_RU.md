# Chelsy AI Desktop 0.6 — Unified UI update

## Что нового
- Более просторный чат и фирменный экран приветствия.
- Аватар Chelsy на ответах, копирование сообщений.
- Три быстрых шаблона вопросов (подставляются в поле, ничего не отправляют автоматически).
- Отдельная форма добавления персональных фактов в SQLite.
- Более читабельные состояния кнопок, адаптивная вёрстка и поддержка уменьшения анимации.
- Сохранены Ollama, существующая история, исследование сайтов и разделение аккаунтов.

## Сборка на Windows
1. Установите Python 3.11 и Inno Setup 6/7.
2. Распакуйте папку в путь без кириллицы, например E:\ChelsyBuild06.
3. Запустите BUILD_INSTALLER.bat.
4. После успешных тестов и сборки откройте installer\ChelsyAI_Setup_0.6.exe.
5. Устанавливайте поверх старой версии, не удаляя %LOCALAPPDATA%\ChelsyAI.

**Важно:** готового exe внутри архива нет, сборка выполняется на Windows. Режим Host/Client и Android-приложение пока не реализованы; не открывайте локальный порт в интернет.
