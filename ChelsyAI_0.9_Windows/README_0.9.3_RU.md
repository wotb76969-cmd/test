# Chelsy AI 0.9.3 — инструкция

Промежуточный релиз (не 1.0). Совместим с базой, аккаунтами и клиентами 0.9.2.

## Из чего состоит

| Программа | Где работает | Что делает |
|---|---|---|
| **Chelsy AI** (Desktop) | ноутбук владельца | интерфейс чата в браузере на `127.0.0.1`, исследования, база знаний, память, настройки |
| **Chelsy AI Host** | ноутбук владельца | API для телефона и других ПК; модель Ollama, база знаний, синхронизация |
| **Chelsy AI Client** | любой Windows-ПК | отдельный клиент, Ollama **не нужна**, подключается к Host |
| **Chelsy AI для Android** | телефон | клиент Host с входом через аккаунт Chelsy Group |
| **Сайт Chelsy Group** | интернет | регистрация, вход, просмотр облачной истории |

Аккаунт один для всех: Supabase Auth проекта Chelsy Group.

## 1. Установка на ноутбук владельца (Host)

1. Установи [Ollama](https://ollama.com/download/windows) и модель. Рекомендации:
   - 16 ГБ RAM: `ollama pull qwen3:8b` (лучший русский) или `gemma3:12b`;
   - 8 ГБ RAM: `ollama pull gemma3:4b` или `qwen3:4b`;
   - для смыслового поиска по базе знаний: `ollama pull nomic-embed-text`.
2. Запусти `ChelsyAI_Host_Setup_0.9.3.exe` (права администратора не нужны). Обновление поверх 0.9.x сохраняет данные.
3. «Chelsy AI — настройка Supabase»: URL проекта и **publishable**-ключ уже подставлены; при желании укажи UUID администратора (владельца).
4. Запусти **Chelsy AI** — откроется браузер. При первом запуске база автоматически обновится до схемы v3; резервная копия появится в `%LOCALAPPDATA%\ChelsyAI\data\backups`.
5. Для доступа с телефона/другого ПК запусти **Chelsy AI Host** и в отдельном окне:
   ```
   tailscale serve --bg 8787
   ```
   Адрес вида `https://ноутбук.имя-сети.ts.net` вводится в клиентах. **Не** открывай порт на роутере и **не** используй Tailscale Funnel.
6. Онлайн-поиск (необязательно): ключ Brave Search API в переменной окружения `CHELSY_BRAVE_SEARCH_KEY` на ноутбуке. Клиентам ключ не передаётся. Без ключа Chelsy честно сообщает, что поиск недоступен.

## 2. Windows Client

`ChelsyAI_Client_Setup_0.9.3.exe` → адрес Host (Tailscale), email и пароль аккаунта Chelsy Group. «Запомнить вход» сохраняет только refresh-токен, зашифрованный Windows DPAPI (пароль не сохраняется).

## 3. Android

Установи `ChelsyAI_Android_0.9.3.apk` (разреши установку из этого источника), войди тем же аккаунтом и укажи адрес Host. На телефоне должен быть включён Tailscale. Если Host выключен, приложение покажет облачную историю только для чтения.

## 4. Supabase (один раз, владельцу проекта)

В SQL Editor по порядку: `supabase/001_chelsy_ai_data.sql`, `002_cloud_sync_indexes.sql` (если ещё не применены), затем **`003_conversations_soft_delete.sql`**. Проверка: `003_verify_rls.sql`. Откат: `003_rollback.sql` (тексты сообщений и память сохраняются). Без 003 всё работает в режиме совместимости 0.9.2 (без синхронизации диалогов).

## 5. Пользование

- **Новый чат**, поиск по истории, избранное (☆), переименование и удаление — в боковой панели.
- Кнопки у сообщений: копировать, повторить ответ (↻), редактировать своё сообщение (✎), 👍/👎.
- **■** останавливает генерацию; сгенерированная часть сохраняется.
- **🌐 Поиск в интернете** — переключатель под полем ввода. Ответы с поиском содержат список источников с датами.
- 📎 — текстовые файлы и код (до 4 файлов).
- **Chelsy Pulse** (индикатор вверху): готова / генерирует / ищет / синхронизирует / сервер недоступен.

### Исследования и база знаний
«Изучи документацию FastAPI», «исследуй …» в чате или раздел **Исследования**: тема или ссылка → Chelsy читает открытые страницы (robots.txt, ограничение частоты, только публичные адреса) → в разделе видны найденные материалы, даты, оценка доверия → ты решаешь, что добавить в **личную** или (владелец) **общую** базу. Обновлённые страницы сохраняются как новые версии, старые не удаляются. Раздел **База знаний** показывает документы, возможные противоречия между источниками и позволяет проверить поиск.

Периодические исследования (владелец) работают только по доменам из списка разрешённых источников.

> Пополнение базы знаний — это **не** переобучение модели.

### Настоящее дообучение (необязательно, вручную)
Отдельный процесс для владельца, ничего не запускается автоматически:
```
python -m training.finetune export --out data\training\run1        # только 👍-ответы пользователей с согласием
python -m training.finetune train --data data\training\run1 --confirm   # внешний тренер из CHELSY_TRAIN_COMMAND (нужна GPU)
python -m training.finetune register --name chelsy-ft:v1 --gguf model.gguf --base qwen3:8b --data data\training\run1
python -m training.finetune evaluate --name chelsy-ft:v1 --baseline qwen3:8b
python -m training.finetune activate --name chelsy-ft:v1      # только если оценка не хуже базовой
python -m training.finetune rollback
```
Согласие на использование оценённых ответов включается в «Настройки → Поведение».

### Оценка моделей
«Настройки → Оценить установленные модели» или `python model_eval.py` — набор русских/английских вопросов, автоматическая оценка языка, связности, длины; отчёт в `data\model_eval`.

## 6. Резервные копии и откат базы

```
ChelsyDB.exe status          # версия схемы и таблицы
ChelsyDB.exe backup          # ручная копия
ChelsyDB.exe rollback 1      # вернуть состояние до обновления 0.9.3 (текущее тоже сохраняется)
```
(из исходников: `python migrations.py …`).

## 7. Сборка из исходников

- Windows: `BUILD_INSTALLER.bat` (Python 3.11 + Inno Setup 6). Сначала выполняются все тесты; при ошибке сборка останавливается. Подпись: переменные `CHELSY_SIGN_PFX`, `CHELSY_SIGN_PASSWORD`.
- Android: `Android_Client\BUILD_ANDROID_APK.bat` (Flutter 3.50, Android SDK, JDK 17, `android\key.properties`).
- Автоматически: GitHub Actions `.github/workflows/build-clients.yml` (артефакты `ChelsyAI-0.9.3-Windows`, `ChelsyAI-0.9.3-Android`). Секреты для подписи описаны в начале файла.

## 8. Решение проблем

| Симптом | Что сделать |
|---|---|
| «Ollama недоступна» | запусти Ollama, проверь `ollama list` |
| Клиент: «Хост недоступен» | ноутбук включён, Host запущен, `tailscale serve status`, Tailscale на устройстве включён |
| Порт 7860 занят | Desktop сам выберет 7861–7890; или задай `GRADIO_SERVER_PORT` |
| Ответы на английском у маленькой модели | поставь `qwen3:8b`/`gemma3:4b`; Chelsy один раз перегенерирует ответ с исправлением языка |
| Нет синхронизации диалогов | примени `supabase/003_conversations_soft_delete.sql` |
| Журналы | `%LOCALAPPDATA%\ChelsyAI\runtime.log`, `error.log`, `client.log` |
