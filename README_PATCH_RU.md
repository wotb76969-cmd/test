# Chelsy AI 0.9.2 — исправление русского языка и ответа о самообучении

## Что исправлено

- На вопрос «Ты самостоятельно изучаешь интернет?» Chelsy теперь отвечает корректно на русском языке и не притворяется, что переобучает веса модели.
- Для русских вопросов расширена инструкция языковой модели.
- Если модель вернула заметную смесь русских и английских фраз, Chelsy делает **одну** попытку переписать ответ локально через установленную Ollama-модель. Это не переводит код, ссылки и технические названия.
- Инструменты погоды, поиска Brave, Supabase Auth, Host/Client и текущая SQLite-база не изменены.

## Установка

1. Сделай резервную копию `%LOCALAPPDATA%\ChelsyAI`.
2. Распакуй архив с исходниками.
3. В папке `ChelsyAI_0.9_Windows` запусти `BUILD_INSTALLER.bat`.
4. После успешной сборки используй установщик из папки `installer`.

Если уже собираешь проект 0.9.1, можно вместо полной распаковки заменить файл `core.py` и добавить рядом **новый** файл `response_quality.py` и `test_response_quality.py`. В таком случае пересобери установщик: изменение Python-файлов не меняет уже установленный EXE автоматически.

## Как проверить

1. «Ты самостоятельно изучаешь интернет?» — ответ должен объяснять отличие веб-поиска от переобучения.
2. «Как дела?» — короткий ответ по-русски.
3. «Какая погода в Москве?» — при работающем интернете фактическая погода от Open-Meteo.
4. «Объясни Python в двух предложениях» — основной текст должен быть на русском.
5. «Найди актуальную информацию об ИИ» — для общего поиска требуется `CHELSY_BRAVE_SEARCH_KEY` на сервере.

## Ограничения

Проверено 47 Python-тестов в среде разработки. Windows EXE и реальная модель Ollama здесь не запускались. Маленькая модель `llama3.2:1b` всё ещё может ошибаться, а повторная формулировка иногда занимает больше времени. Для улучшения качества ответов рассмотри модель `qwen3:4b` (если хватает ресурсов): `ollama pull qwen3:4b`, затем выбери её в интерфейсе.

Это обновление **не добавляет автономное переобучение модели**, не обходит все сайты и не включает веб-поиск без ключа API.
