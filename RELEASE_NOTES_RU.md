# Chelsy AI 0.9.3 — промежуточный релиз

## Новое
- **Chelsy Intelligence Engine** (`intelligence.py`): живая персона Челси вместо шаблонов, ответ на языке последнего сообщения, адаптивная длина, контекстное окно по токенам, настраиваемые параметры генерации, потоковая генерация с остановкой, проверки языка/повторов/бессвязности/ложных заявлений о поиске и одна контролируемая перегенерация, поддержка любых установленных моделей Ollama, оценка моделей (`model_eval.py`).
- **Chelsy Autonomous Knowledge** (`knowledge/`): поиск, безопасная загрузка (SSRF-защита, robots.txt, лимиты), извлечение текста и дат, дедупликация, версии, FTS5 + эмбеддинги, оценка источников и противоречий, фоновые и периодические исследования с проверкой пользователем. Это RAG, а не переобучение.
- **Контролируемое дообучение** (`training/`): экспорт проверенного датасета, внешний тренер, порог качества, реестр моделей, откат.
- **Диалоги**: новый чат, поиск по истории, избранное, переименование, мягкое удаление, редактирование и повтор, оценки.
- **Новый Desktop UI**, **Host API v2** (стриминг NDJSON, остановка, исследования, база знаний), **новый Windows Client** (DPAPI), **новый Android-клиент** (Keystore, HTTPS-only, обязательная release-подпись).
- **Supabase 003**: диалоги и мягкое удаление с откатом; проверено на PostgreSQL 16.
- **Версионированные миграции SQLite** с автоматическими резервными копиями и откатом (`ChelsyDB.exe`).

## Обновление: автоизучение и локальные данные
- **Автоизучение интернета** (`knowledge/autolearn.py`): после ответа с реальным поиском Chelsy в фоне читает источники и сохраняет надёжные в личную базу знаний; при пустой базе по вопросу сама изучает тему (если разрешён поиск в сообщении и есть ключ API). Пороги надёжности, дневные лимиты, страницы с инструкциями для ИИ — только на проверку.
- **Журнал обучения** (миграция SQLite v4 `learning_log`): Desktop → База знаний, Windows Client → База знаний, Android → Исследования, API `/api/v2/learning`.
- **Локальные данные на клиентах**: Windows Client — `client_cache.db`, Android — закрытая папка приложения; история доступна без хоста, удаляется при выходе.
- **Хост для всех устройств**: `ChelsyHost.exe --doctor` (проверка готовности), `--setup-tailscale` (публикация в частной сети и адрес для клиентов), автозапуск при входе в Windows, ярлыки в меню «Пуск».
- Исправлена кодировка русских названий ярлыков в установщиках (UTF-8 BOM для Inno Setup).
- Новый файл **`Установка.md`**.

## Исправлено
- Потеря сообщений при синхронизации с двух хостов (одинаковые `host:<id>`).
- Повторная выгрузка всей истории при каждой синхронизации.
- DNS-rebinding в обходчике; robots.txt 404 больше не блокирует сайт.
- Тест-импорт клиента без Tk.

## Совместимость
Старые клиенты 0.9.2 работают с Host 0.9.3 (`/api/chat`, `/api/history`, …). Без миграции 003 облако работает в режиме 0.9.2.

## Не входит
- Готовые EXE/APK в этом коммите: собираются CI или скриптами (см. `TEST_REPORT_0.9.3_RU.md`).
- Автоматическое изменение весов модели.

# Chelsy AI 0.9 — Client/Server Beta

## Добавлено
- Server API v0.9, защита по Supabase Auth; Basic выключен по умолчанию.
- Постраничная синхронизация облачных сообщений и личной памяти с Supabase RLS.
- Отдельный Windows Client Installer (`CLIENT_ONLY.iss`, `BUILD_CLIENT_ONLY.bat`).
- В полном Windows Installer упакованы Desktop, Host, Client, Config и утилиты миграции.
- Android Flutter client с логином Supabase и общением с Host через HTTPS.
- Сборщик Android APK и встроенное фирменное изображение Chelsy AI.
- Веб-страница `history.html` для чтения синхронизированных сообщений из аккаунта сайта.
- Повторная синхронизация безопасна по `legacy_id`, разделение по `user_id`.

- GitHub Actions workflow для облачной сборки EXE и APK (ещё не запускался).

## Не входит в этот выпуск
- Готовые `.exe` / `.apk` бинарники — нужны Windows / Android SDK + Flutter.
- Полноценное постоянное обучение нейросети весами; здесь только накопление знаний.
- Публичный хостинг, платежи и гарантия доступности ноутбука 24/7.
- Гарантированная синхронизация конфликтующих изменений в общем чате при параллельных ответах: beta, требуется тестирование на устройствах.

## Проверено в среде сборки исходников
- `python -m unittest discover -q` — 36 тестов успешны.
- Python compileall — успешно.
- JS синтаксис страницы облачной истории — успешно.
- Реальная сборка Windows EXE и Android APK здесь не выполнялась: соответствующих SDK нет.
