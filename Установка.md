# Установка Chelsy AI 0.9.3

Как это устроено: нейросеть работает **на одном компьютере — хосте** (обычно ваш ноутбук с Ollama). Windows-клиент и Android-приложение — это «окна» к нейросети: они подключаются к хосту через защищённую частную сеть **Tailscale**, поэтому на телефоне и других ПК Ollama не нужна. Вход везде один — аккаунт **Chelsy Group** (тот же, что на сайте).

```
 Телефон (Android) ─┐
                    ├── Tailscale (HTTPS, только ваши устройства) ──► Хост: Chelsy AI Host + Ollama + база знаний
 Другой ПК (Client) ┘
```

---

## 0. Где взять установочные файлы

Файлы собираются автоматически в GitHub Actions:

1. Откройте репозиторий → вкладка **Actions** → последний запуск **«Chelsy AI 0.9.3 — tests and installers»** с зелёной галочкой.
2. Внизу страницы в разделе **Artifacts** скачайте:
   - `ChelsyAI-0.9.3-Windows` → внутри `ChelsyAI_Host_Setup_0.9.3.exe` и `ChelsyAI_Client_Setup_0.9.3.exe`;
   - `ChelsyAI-0.9.3-Android` → внутри `ChelsyAI_Android_0.9.3.apk`.
3. Распакуйте zip-архивы. Рядом лежит `SHA256SUMS.txt` — контрольные суммы. Проверить файл в Windows:
   ```
   certutil -hashfile ChelsyAI_Client_Setup_0.9.3.exe SHA256
   ```
   Результат должен совпасть со строкой в `SHA256SUMS.txt`.

> Артефакты хранятся 30 дней. Новый запуск сборки — любой push в ветку или кнопка **Run workflow**.

## 1. Хост — компьютер, на котором работает нейросеть

Нужен один раз. Рекомендуется ПК/ноутбук с 16 ГБ ОЗУ (минимум 8 ГБ), Windows 10/11 x64.

### 1.1. Ollama и модель
1. Установите Ollama: https://ollama.com/download/windows
2. Откройте «Командную строку» и скачайте модель:
   ```
   ollama pull qwen3:8b
   ```
   (на 8 ГБ ОЗУ — `ollama pull gemma3:4b` или `ollama pull qwen3:4b`).
3. Для смыслового поиска по базе знаний (рекомендуется):
   ```
   ollama pull nomic-embed-text
   ```

### 1.2. Chelsy AI Host
1. Запустите `ChelsyAI_Host_Setup_0.9.3.exe`. Права администратора не нужны.
   Если Windows покажет «Windows защитила ваш компьютер» — это потому, что установщик не подписан сертификатом издателя. Если файл скачан из вашего репозитория и контрольная сумма совпала: **Подробнее → Выполнить в любом случае**.
2. На шаге «Дополнительные задачи» оставьте галочку **«Запускать Chelsy AI Host при входе в Windows»** — тогда нейросеть будет доступна устройствам сразу после включения ноутбука.
3. Меню «Пуск» → **«Chelsy AI — настройка Supabase»**: адрес проекта и публичный ключ уже подставлены. В поле *Admin Supabase user UUID* впишите UUID своего аккаунта (Supabase → Authentication → Users) — это сделает вас владельцем: общая база знаний и настройки автоизучения. Нажмите **Save**.
4. Обновление поверх 0.9.x сохраняет историю и память: перед обновлением базы создаётся резервная копия в `%LOCALAPPDATA%\ChelsyAI\data\backups`.

### 1.3. Доступ с телефона и других ПК (Tailscale)
1. Установите Tailscale: https://tailscale.com/download и войдите (Google/Microsoft/GitHub-аккаунт). Этим же аккаунтом Tailscale вы будете входить на телефоне и других ПК.
2. В админке Tailscale (https://login.tailscale.com/admin/dns) включите **MagicDNS** и **HTTPS Certificates** — один раз.
3. Меню «Пуск» → **«Chelsy AI Host — включить доступ с устройств (Tailscale)»**. В окне появится адрес вида:
   ```
   https://ваш-ноутбук.tail1234.ts.net
   ```
   **Запишите его** — он нужен на всех устройствах.
4. Запустите **«Chelsy AI Host»** (или перезагрузите ПК, если включили автозапуск).

> Безопасность: хост слушает только `127.0.0.1`; доступ есть только у устройств вашей сети Tailscale. **Не** открывайте порт 8787 на роутере и **не** включайте Tailscale Funnel.

### 1.4. Проверка готовности
Меню «Пуск» → **«Chelsy AI Host — проверка готовности»** (или `ChelsyHost.exe --doctor`). Пример:

```
[   OK    ] Локальные данные       C:\Users\...\ChelsyAI\data · схема v4/4 · резервных копий: 4
[   OK    ] Supabase Auth          https://….supabase.co
[   OK    ] Ollama и модели        установлены: qwen3:8b · по умолчанию: qwen3:8b
[   OK    ] Автоизучение           включено · из поиска: да · любопытство: да · лимит в день: 20
[   OK    ] Chelsy Host            запущен на 127.0.0.1:8787
[   OK    ] Доступ с устройств     адрес для клиентов: https://ваш-ноутбук.tail1234.ts.net
Готово к работе на всех устройствах.
```
Для каждого пункта со статусом «ОШИБКА» или «ВНИМАНИЕ» указано, что сделать.

### 1.5. Онлайн-поиск и автоизучение интернета (рекомендуется)
Чтобы Chelsy искала свежую информацию и **сама пополняла знания**, нужен ключ Brave Search API (https://brave.com/search/api/). Задайте его **только на хосте** (клиентам он не передаётся):
```
setx CHELSY_BRAVE_SEARCH_KEY "ваш_ключ"
```
и перезапустите Chelsy AI Host.

Что делает автоизучение:
- после ответа с поиском в интернете Chelsy в фоне читает найденные страницы и **сохраняет надёжные в вашу личную базу знаний** — в следующий раз ответ берётся из локальных данных, даже без интернета;
- если в базе знаний нет ничего по вашему вопросу, Chelsy **сама изучает тему** (только если в этом сообщении включён «Поиск в интернете»);
- владелец может задать периодическое изучение разрешённых сайтов (Desktop → Исследования);
- соблюдаются robots.txt и лимиты частоты; сомнительные страницы и страницы с «инструкциями для ИИ» не сохраняются автоматически, а ждут проверки в «Исследованиях»;
- всё записывается в **журнал автоизучения**: Desktop → База знаний, Windows Client → «База знаний», Android → «Исследования»;
- выключить или изменить лимиты: Desktop → База знаний → «Автоизучение интернета» (только владелец).

Это пополнение базы знаний, а не переобучение модели.

### 1.6. Где хранятся данные хоста
| Что | Где |
|---|---|
| Диалоги, память, база знаний, журнал обучения | `%LOCALAPPDATA%\ChelsyAI\data\chelsy.db` |
| Резервные копии базы | `%LOCALAPPDATA%\ChelsyAI\data\backups` |
| Настройки Supabase | `%LOCALAPPDATA%\ChelsyAI\supabase.json` (только публичный ключ) |
| Журналы программы | `%LOCALAPPDATA%\ChelsyAI\runtime.log`, `error.log` |

При входе через аккаунт Chelsy Group диалоги и память также синхронизируются с облаком (Supabase) — так история видна на всех устройствах и на сайте.

## 2. Windows Client — другой компьютер

Нейросеть на этом ПК не нужна — только интернет и Tailscale.

1. Установите Tailscale (https://tailscale.com/download) и войдите **тем же аккаунтом Tailscale**, что и на хосте.
2. Запустите `ChelsyAI_Client_Setup_0.9.3.exe` (права администратора не нужны; про предупреждение SmartScreen — см. п. 1.2).
3. Откройте **Chelsy AI Client** и заполните:
   - **Адрес Chelsy Host** — адрес из п. 1.3 (`https://….ts.net`);
   - **Email и пароль** аккаунта Chelsy Group.
4. «Запомнить вход» — сохраняется только токен сессии, зашифрованный Windows (DPAPI); пароль не сохраняется.
5. **Локальная копия:** открытые диалоги сохраняются на этом ПК (`%LOCALAPPDATA%\ChelsyAI\client_cache.db`). Если хост выключен, клиент покажет сохранённую историю только для чтения. При нажатии **«Выйти»** копия удаляется.

Возможности: новый чат, поиск по истории, избранное (★), переименование, удаление, остановка (■), повтор, изменение последнего сообщения, копирование ответа, прикрепление текстовых файлов (📎), выбор модели, переключатель «Поиск в интернете», окна «Исследования» и «База знаний» с журналом автоизучения.

## 3. Android

Требуется Android 6.0 или новее.

1. Установите **Tailscale** из Google Play и войдите **тем же аккаунтом Tailscale**, что и на хосте. Включите подключение (переключатель «Connected»).
2. Скопируйте `ChelsyAI_Android_0.9.3.apk` на телефон (или скачайте артефакт прямо на телефоне).
3. Откройте файл. Android попросит разрешить установку из этого источника (браузер/«Файлы») → **Настройки → Разрешить из этого источника** → назад → **Установить**.
   Google Play Защита может предупредить о неизвестном приложении → **Подробнее → Всё равно установить**.
4. Откройте **Chelsy AI** и введите:
   - **Адрес Chelsy Host** — `https://….ts.net` из п. 1.3;
   - **Email и пароль** аккаунта Chelsy Group.
5. **Локальная копия:** диалоги сохраняются в закрытой папке приложения на телефоне (недоступна другим приложениям, не попадает в резервные копии). Без связи с хостом приложение покажет сохранённые диалоги, а если их нет — историю из облака. При выходе из аккаунта копия удаляется.

**Обновления APK:** новая версия устанавливается поверх старой, только если подписана тем же ключом. Пока в сборке не задан постоянный ключ (секреты `ANDROID_KEYSTORE_*` в GitHub), каждую новую сборку нужно ставить после удаления предыдущей (данные на хосте и в облаке при этом не теряются).

## 4. Проверка, что всё работает на всех устройствах

1. На хосте: «Проверка готовности» → «Готово к работе на всех устройствах».
2. На телефоне: «Как дела, Челси?» — ответ приходит постепенно, индикатор вверху мигает.
3. На Windows Client: в списке слева виден диалог, начатый на телефоне (после синхронизации ⟳).
4. Спросите «Найди последние новости Python» — в ответе ссылки с датами; через минуту в журнале автоизучения появится запись «📚 изучено».
5. Выключите хост → клиенты показывают «Хост недоступен» и сохранённую историю.

## 5. Частые проблемы

| Проблема | Решение |
|---|---|
| «Хост недоступен» | ноутбук включён и не спит; Chelsy AI Host запущен; Tailscale подключён на обоих устройствах; адрес начинается с `https://` и заканчивается на `.ts.net` |
| Адрес не открывается | на хосте снова «Включить доступ с устройств (Tailscale)»; в админке Tailscale включён HTTPS |
| «Неверный email или пароль» | войдите на сайте Chelsy Group; подтвердите email по письму |
| «Ollama недоступна на хосте» | запустите Ollama; `ollama list` должен показать модель |
| Нет свежих новостей / автоизучение не работает | задайте `CHELSY_BRAVE_SEARCH_KEY` (п. 1.5) и проверьте «Проверку готовности» |
| Ответы медленные | используйте модель поменьше (`gemma3:4b`) или ПК с видеокартой |
| APK не устанавливается поверх старого | удалите старую версию (разные ключи подписи) |
