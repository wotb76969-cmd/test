Связаться с нами
Chelsy уже доступен?

Пока нет. Chelsy находится на раннем этапе разработки. Сейчас можно зарегистрировать интерес к продукту — доступ будет открываться по мере готовности.

Нужно ли платить при регистрации?

Нет. Запись на ранний доступ бесплатна. Мы не принимаем оплату на этом сайте.

Указанные цены окончательные?

Нет. Цены, функции и лимиты пока являются предложением. Перед коммерческим запуском они могут измениться.

В чём разница между тарифами?

Start — для знакомства, Plus — для регулярных задач, Pro — для более интенсивного использования, Teams — для организаций и совместной работы.

Как узнать о запуске?

Оставьте заявку на ранний доступ. В этой демонстрационной версии форма сохраняет запись локально в браузере; для настоящей рассылки потребуется подключить сервер.
