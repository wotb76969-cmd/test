# Chelsy AI 0.9.1 — актуальные знания и простой диалог

## Что исправлено

- «Привет» и «Как дела?» работают без обращения к маленькой Ollama-модели.
- «Какая погода в Москве?» запрашивает актуальные данные Open-Meteo (интернет нужен; город обязателен). Вопрос без города попросит уточнение.
- «Найди в интернете ...», «Последние новости ...», «Что сегодня ...» включают живой поиск Brave Search. Нужен отдельный API-ключ; без него Chelsy честно сообщает об отсутствии веб-поиска.
- Обработка живых результатов с ссылками и предупреждениями о сбоях.
- Существующие Host, Client, Supabase, локальная память и исправление конфликта портов перенесены из 0.9.

## Как установить

1. Скопируйте резервную копию `%LOCALAPPDATA%\ChelsyAI`.
2. Распакуйте ZIP и в `ChelsyAI_0.9_Windows` запустите `BUILD_INSTALLER.bat` на Windows с Python 3.11 и Inno Setup.
3. Установите новый EXE после сборки. Готового бинарника в ZIP нет.
4. Для погоды ключ не нужен, только подключение к интернету.
5. Для общего веб-поиска создайте Brave Search API key (это может быть платно) и задайте переменную окружения на **ноутбуке-хосте**, например в PowerShell:

   `[Environment]::SetEnvironmentVariable("CHELSY_BRAVE_SEARCH_KEY", "ВАШ_КЛЮЧ", "User")`

   Затем закройте и снова запустите Chelsy AI / Host. Не добавляйте API-ключ в архив, GitHub, Android APK, сайт или Windows Client.
6. Для более качественных рассуждений при наличии ресурсов можно переключиться на более сильную модель Ollama; 1b-модель ограничена по качеству.

## Важно

- Онлайн-поиск является поиском, а не дообучением весов языковой модели.
- Автономный обход *всего* интернета невозможен; для долгосрочного исследования остаётся ограниченный crawler по выбранным источникам и с учётом robots.txt.
- Brave API использует внешний сервис; поисковые запросы передаются провайдеру. Open-Meteo получает название города и координаты. Не отправляйте через поиск пароли или личные данные.
- Проверены автоматические Python-тесты, но Windows EXE, сеть на компьютере и актуальные ответы от сервисов здесь не проверялись.
